# Security policy

## Reporting a vulnerability or data-loss risk

Please do not disclose a vulnerability, a possible unsafe deletion, or other
security-sensitive details in a public issue or pull request.

Private vulnerability reporting is currently **not enabled** for this
repository, and no private security contact is published here. The maintainer
must enable GitHub's private vulnerability reporting for this repository or
publish a dedicated private contact before sensitive reports can be submitted.
Once enabled, use the repository's **Security** tab and select **Report a
vulnerability**.

When private reporting is available, include the affected Terso version,
macOS version and architecture, a concise impact description, and reproduction
steps that use synthetic or non-sensitive data. For deletion risks, describe
the paths and circumstances at a high level. Redact usernames, home-directory
paths, personal filenames, secrets, and other personal data from logs and
screenshots.

If you are unsure whether a report is sensitive, do not post its details
publicly. The maintainer needs to decide and configure a private reporting
channel before this repository can receive private vulnerability reports.
